- منطق الأسئلة، التصحيح، المؤقّت، LocalStorage، السجل، الإتقان — **بلا أي تغيير منطقي**.

### التغيير الوحيد في JS (عرض فقط)

### مقايضات
- **`--color-1` غير صالح كنص** (2.43:1). استُخدم للحدود فقط، والنص الخافت مشتق منه لونيًا لا حرفيًا.
- **`--color-7` للشكل لا للنص** (3.79:1). استُخدم لحلقة التركيز والأشكال، وشارة الوقت تستخدم `--urgent` الآمن نصيًا.
- **ألوان المقررات** لم تعد متمايزة بشدة كما كانت (كلها في عائلة واحدة) — لكنها الآن متسقة مع العلامة، واسم المقرر مكتوب بجانب اللون دائمًا.
