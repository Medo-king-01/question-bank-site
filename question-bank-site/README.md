## 🌐 النشر على GitHub Pages

الريبو مجهّز للنشر بضغطة:

1. اعمل رفع للريبو (انظر [الرفع لأول مرة](#-الرفع-لأول-مرة)).
2. من صفحة الريبو: **Settings → Pages → Source: GitHub Actions**.
3. أي `push` على `main` بيشغّل الـ workflow الجاهز في `.github/workflows/pages.yml` وينشر الموقع تلقائيًا على:
   `https://<USERNAME>.github.io/<REPO>/`

> بديل أسرع بدون Actions: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `root`** — الموقع `index.html` في جذر الريبو فهيشتغل على طول.

> **مهم لـ PWA:** لو نشرت بالطريقة اليدوية دي، لازم تكون `manifest.json` و`sw.js` في **جذر الموقع** (هما كذلك أصلًا بعد `build_site.py`). الـ service worker بيتحكم في الصفحات اللي تحت مساره بس، فمينفعش يبقى جوه `src/`.

## 📲 العمل دون اتصال (PWA)

بعد أول زيارة، الموقع يحفظ نفسه على جهازك ويشتغل بدون إنترنت:

| الحاجة | التفاصيل |
|---|---|
| **التثبيت** | من Chrome/Edge: أيقونة التثبيت في شريط العنوان. من Safari على iOS: «مشاركة → إضافة إلى الشاشة الرئيسية». |
| **الصفحة** | `manifest.json` في جذر الموقع، عربي و`dir: rtl`، بأيقونات 192 و512 ونسخة `maskable`. |
| **التخزين** | `sw.js` يحفظ نسخة من `index.html` والأيقونات والصورة الشخصية (≈757 KB إجمالًا). **فشل حفظ `index.html` يُفشل التثبيت بالكامل** — لا وعد بعمل دون اتصال لا يمكن الوفاء به؛ أما الأيقونات والصور فاختيارية. الكتابة إلى الكاش **تُنتظَر** قبل إنهاء الطلب، وأي استجابة بلا `Content-Type` لا تُحفظ (لا يمكن التحقق منها). |
| **فتح الصفحة** | **الشبكة أولًا** ثم النسخة المحفوظة — يعني اللي فاتح النت دايمًا بيشوف أحدث نسخة، واللي قافل النت بيلاقي آخر نسخة حفظها. **الصفحة لا تُحفظ إلا لو الاستجابة ناجحة و HTML** — صفحة خطأ 404 ما تمسحش النسخة الصالحة. |
| **التحديث** | لو فيه نسخة أحدث، يظهر زر «تحديث» أسفل الشاشة بدل ما تفضل على نسخة قديمة للأبد. |
| **اسم الكاش** | مشتق من بصمة محتوى البناء (`sw.js` مبني بـ hash)، فأي تعديل في الأسئلة ينتج كاش جديد ويُحذف القديم تلقائيًا. |
| **بدون نت لأول مرة** | لو الكاش فاضي والجهاز غير متصل، تظهر رسالة عربية واضحة بدل شاشة بيضاء. |

**الصورة الشخصية:** أصلها 946 KB لعرض 360px بس. بقت تُقدَّم بصيغة WebP (43 KB) مع PNG محسّن كاحتياطي (120 KB) عبر `<picture>` — حمولة التثبيت نزلت من **1519 KB إلى 757 KB**.

## 🔧 إعادة البناء بعد أي تعديل

عدّل `src/data.json` أو `src/app_template.html` ثم:

```bash
python3 scripts/build_site.py            # يكتب index.html (≈571 KB) + manifest.json + sw.js
python3 scripts/extract/audit.py         # فحص البيانات: لازم ينتهي بـ OK
python3 scripts/extract/audit.py --strict # نفس الفحص + التحذيرات كأخطاء

npm install --no-save jsdom              # مرة واحدة (أداة اختبار فقط)
node tests/run.mjs                       # 171 اختبارًا سلوكيًا — لازم PASS
```

> **متطلب الاختبارات:** Node **22.22.2 أو أحدث** — `jsdom 31` يعتمد على واجهة `zstd` المضافة في Node 22.7. الموقع نفسه لا يحتاج Node إطلاقًا؛ القيد على أداة الاختبار فقط، والمشغّل يعطي رسالة واضحة لو الإصدار أقدم.
>
> **مهم:** `index.html` مولَّد ومرفوع مع المصدر. أي تعديل على `src/` يجب أن يتبعه `build_site.py` وإلا سيفشل الـ CI (`git diff --exit-code`).

### الاختبارات

`tests/` تحمّل `index.html` المبني فعلًا داخل `jsdom` وتستخدمه كما يستخدمه الطالب — نقر فعلي على الخيارات وتبديل الوضع وانتظار انتهاء المؤقت:

| الملف | التغطية |
|---|---|
| `tests/data.test.mjs` | سلامة البنك + هجمات XSS على كل مسار عرض |
| `tests/quiz.test.mjs` | التدريب، الامتحان، المؤقت، الجلسة، سجل الأخطاء |
| `tests/a11y.test.mjs` | دلالات ARIA واختصارات الكيبورد |
| `tests/history.test.mjs` | سجل المحاولات والجلسات والتحليلات |
| `tests/search.test.mjs` | البحث داخل المقرر ونطاقه ومعالجة العربية |
| `tests/pwa.test.mjs` | المانيفست والأيقونات، تشغيل الـ service worker فعليًا (تخزين/تفعيل/عمل دون اتصال)، وبانر «غير متصل» |

الـ CI يشغّل وظيفة `mutants` تكسر الموقع عمدًا (تعطيل `esc()` وتعطيل المؤقت) وتتوقع فشل الاختبارات — الضمانة أن الحزمة لا تصبح شكلية مع الوقت.

`jsdom` أداة اختبار فقط. **بناء الموقع ونشره يحتاجان `python3` وحدهما** — لا npm ولا pip.

## 🧩 استخراج الأسئلة من PDF (اختياري)

السكربتات في `scripts/extract/` هي اللي بنت `src/data.json` من ملفات الـ PDF الأصلية
(استخراج على مستوى الحروف مع إصلاحات نصية وإجابة نموذجية لكل سؤال):

```bash
pip install pymupdf
mkdir -p pdfs && cp your-banks/*.pdf pdfs/     # ملفات الـ PDF مش مرفوعة في الريبو
python3 scripts/extract/make_data.py           # يكتب src/data.json
python3 scripts/build_site.py
```

> ملفات الـ PDF الأصلية **غير مضمّنة** في الريبو (حقوق مواد المقررات) — الريبو بيشمل الناتج النهائي `src/data.json`.
